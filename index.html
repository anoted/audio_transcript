Speech Transcriber

Live, offline speech-to-text for your microphone and computer audio at the same time. You're [Mic], everyone on the call is [PC]. Save the session as Markdown and hand it to an LLM for a summary and next steps.

View on GitHub Install

How it works

Capture

The mic and a loopback of your speakers are each recorded on their own thread in 100 ms blocks.

Cut phrases

A running noise floor detects speech. 0.6 s of silence ends a phrase; blips under 0.3 s are dropped.

Transcribe

One shared faster-whisper model handles phrases from both sources in order, on GPU or CPU.

Save

Ctrl+S writes saved_histories/<session>.md with an LLM-ready instruction on top.

Features

  • Runs entirely on your machine with faster-whisper. After the first model download, no network needed.
  • Uses CUDA when it works, otherwise falls back to CPU automatically.
  • Pick tiny.en, base.en or small.en to trade speed for accuracy.
  • Copy All puts the instruction and transcript on the clipboard in one click.
  • Builds into a single Windows .exe with build.bat.

Quick start

pip install -r requirements.txt
python transcriber.py

On Linux, use ./setup.sh then ./run.sh. See the README for GPU setup and building the exe.
